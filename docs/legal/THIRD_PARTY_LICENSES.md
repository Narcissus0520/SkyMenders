# Third-Party Licenses

Phase 0 uses development tooling and runtime libraries through the locked pnpm dependency graph. CI generates a CycloneDX 1.6 SBOM and license inventory; repository publication does not relicense third-party packages. GPL/AGPL or another dependency whose obligations conflict with the product release requires explicit legal review before adoption.

This file becomes the human-reviewed release inventory in Phase 10. The lockfile and generated inventory are evidence inputs, not a substitute for checking bundled runtime, fonts, art, audio, Cocos components, and SDK terms.
