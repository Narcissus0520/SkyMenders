# Asset Provenance Policy

Every release asset records its stable ID, repository path, author/supplier, creation date, original source location, license, commercial scope, modification right, generative-AI status and process, references, reviewer, and release state in `assets/provenance/asset-registry.json`.

Development placeholders must be visibly marked and stay outside `assets/release`. Missing provenance, prohibited licensing, absent font/audio rights, unapproved generated material, or a non-commercial/unapproved state fails the release audit. Source files and purchase/license evidence must be retained outside public distribution when their terms require it.
