# Trademark Review Checklist

The working identifiers are not approved public brands. Before a public name is frozen, record the search date, applicant/owner, relevant China trademark classes, exact and similar Chinese/English marks, China Trademark Office results, WeChat Mini Game results, major search engines, app stores, game databases, domain/social availability, legal reviewer, risks, and final decision.

Professional review is external blocker EXT-004. Passing a casual web search is not release approval.
