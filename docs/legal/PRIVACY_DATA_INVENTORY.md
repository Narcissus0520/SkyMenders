# Privacy Data Inventory

Status: engineering inventory complete for Phase 10; qualified legal review and deployed-environment verification remain blocked by `EXT-002` and `EXT-003`.

| Data                                                  | Purpose                                                                | Source                           | Storage                                                | Retention / deletion                                                         | Public exposure              |
| ----------------------------------------------------- | ---------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------- | ---------------------------- |
| WeChat login code                                     | Exchange for a platform account identifier                             | WeChat client API                | Transit only; never logged or persisted                | Discarded after exchange                                                     | Never                        |
| OpenID                                                | Account lookup and ownership                                           | WeChat server exchange           | PostgreSQL, encrypted transport, server-only           | Until account deletion or legal retention requirement                        | Never                        |
| System codename and original robot avatar ID          | Anonymous leaderboard identity                                         | Server-generated catalog         | PostgreSQL and leaderboard cache                       | Until account deletion; leaderboard rows are removed                         | Yes                          |
| Account progress, settings, saves and replay commands | Provide play, recovery, deterministic verification and support         | Player actions                   | Local device and PostgreSQL; derived Redis cache       | Active account; recovery branches expire after seven days; deletion cascades | Only anonymous score summary |
| Security and audit events                             | Abuse prevention, incident response and privileged-action traceability | Server and administrator actions | Structured operational logs / PostgreSQL audit records | Production retention must be approved before launch                          | Never                        |
| Technical telemetry                                   | Reliability and performance with pseudonymous request IDs              | Client/server runtime            | Approved telemetry backend only                        | Production retention must be approved before launch                          | Never                        |

The V1 client does not request contacts, precise location, microphone, camera, album, phone number, custom avatar, free-text nickname, WeChat nickname/avatar, chat, region, advertising identifiers, or cross-app tracking identifiers. Logs must exclude login codes, OpenID, tokens, request bodies containing saves, and secrets. Account export/correction/deletion requests are authenticated and audited; deletion removes player-owned rows and invalidates sessions.

Before release, the owner must reconcile this inventory against the deployed database, Redis keys, object storage, telemetry fields, SDK network calls, retention jobs, subprocessors, data location, and the final privacy policy. Any mismatch blocks the strict release gate.
