# Release Regression

The release candidate gate runs installation from the lockfile, empty-database migration, old-save migration, all static/unit/property/golden/integration/E2E/content/asset/build/Cocos gates, complete tutorial and expedition flows, recovery and cloud conflicts, daily attempt enforcement, tamper rejection, account deletion, content publication, admin audit, Compose deployment, backup/restore, package audit, and documented real-device checks.

Failures cannot be hidden with skipped tests, weakened assertions, empty mocks, or lowered core coverage thresholds.
