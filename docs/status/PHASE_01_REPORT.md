# Phase 01：确定性运行时

## 阶段目标

建立可被 Node.js、后续 Cocos 客户端、验证 Worker 和未来 PvP 服务端共同复用的确定性权威运行时。相同规则版本、内容版本、根种子、初始状态和指令序列必须得到一致的事件、逐指令检查点和最终状态哈希。

## 主要实现

- `@skymenders/deterministic-runtime`：安全整数固定点运算、整数三角查表、函数式 `xoshiro128**`、八个独立 RNG 子流、规范化序列化、逻辑状态哈希、快照和通用回放执行器。
- `@skymenders/protocol`：严格运行时校验的移动、模块、待机、交互指令，以及接受、移动、模块结算、待机、交互完成、状态检查点事件。
- `@skymenders/replay-runner`：可执行的 Golden 回放验证器和覆盖全部 Phase 1 指令/事件类型的 `runtime-ledger-v1` 固定样例。
- 快照在创建和恢复时校验版本、索引、RNG 状态和状态哈希，并对调用方对象做规范化脱离复制。
- 回放在每次 reducer 调用时提供根种子和规则/内容/回放版本上下文；事件序号、每条指令检查点和最终哈希任一不一致即失败。
- 确定性策略扫描只检查权威包自有 `src/`，不会跟随 pnpm 依赖链接或构建输出，同时仍拒绝 `Math.random()`、`Date.now()` 和 Cocos 权威依赖。

## 架构变化

ADR 0002 固化 `FIXED_SCALE = 1000`、毫度角、整数三角表、显式四字 RNG 状态、命名子流、规范化 JSON 状态和 16 位十六进制逻辑漂移哈希。该哈希只用于确定性漂移和损坏检测，不作为反作弊签名；服务端提交仍需可信复算和加密完整性保护。

权威 reducer 仅接收规范化状态、已验证指令、指令索引和不可变回放上下文，并返回新状态与事件。它不得读取表现层、设备时钟、帧时间或引擎物理结果。

## 数据库或协议变化

未引入数据库、迁移或网络服务。独立兼容性维度变更如下：

| 维度                  | 变更          | 原因                       |

| `replaySchemaVersion` | 0.0.0 → 0.1.0 | 首个可校验 Golden 回放结构 |

客户端、服务端、内容和存档版本仍为 `0.0.0`。Phase 1 快照不是持久化存档格式；数据库、云存档、冲突处理与迁移属于 Phase 7。

## 安全与隐私影响

本阶段不收集身份、设备或其他个人信息，不加入凭证或平台 SDK。所有外部回放/协议输入都通过严格 Zod schema 或运行时不变量校验。状态规模、深度、指令数量和检查点数量均有上限；非安全整数、循环、稀疏数组、非普通对象、非法 RNG 状态和版本不匹配均被拒绝。

逻辑哈希不被描述为加密保护，客户端最终状态也不会在后续排行榜/PvP 中被直接信任。

## 测试结果

- 格式、ESLint、严格 TypeScript、构建、工作区策略、基础设施策略、内容校验、素材审计和秘密扫描：通过。
- 全仓单元与回放测试：76 个通过。
- 单元与回放测试覆盖固定点边界、三角象限、RNG 固定序列/子流隔离/无偏范围、规范化状态限制、UTF-8 哈希、快照篡改、协议非法输入、事件序号、检查点和最终哈希篡改。
- Golden 回放稳定结果：12 个事件，最终哈希 `73b0d3c57d06fa99`；改变根种子会改变最终状态哈希。
- 核心覆盖率：确定性运行时 99.09% statements / 95.00% branches；协议 100% / 100%；回放工具 100% / 90.90%，均高于规定门槛。
- 官方 npm 高危漏洞审计：无已知漏洞；CycloneDX 1.6 SBOM 可正常生成。
- 冻结锁文件安装：Node.js 24.14.0、pnpm 10.31.0 下通过。

最终本地 Gate（含冻结安装、漏洞审计、SBOM 与 `git diff --check`）全部通过。

## 性能结果

Phase 1 单测中包含 1,000 次连续 RNG/哈希重复性执行，整包测试在本机秒级完成。尚未引入地形或弹道负载，因此不宣称战斗性能指标；大型坍塌基准、脏 Chunk 范围和帧预算从 Phase 2 开始测量。

## 内容与素材检查

内容版本仍为 `0.0.0`，现有 manifest 校验通过。未新增发布美术、音频或第三方素材；素材来源审计通过。Golden JSON 是测试数据，不是发布内容或美术占位。

## 已知限制

- 本阶段是运行时地基和契约示例，不包含地形、弹道、完整回合、模块或 AI 规则。
- 逻辑状态哈希不抵抗恶意碰撞或伪造；Phase 8/12 必须在可信环境复算并添加加密完整性控制。
- JavaScript 安全整数范围要求后续地形、弹道和伤害系统显式定义世界边界与中间值上限。
- 本机仍无 Docker CLI；Phase 0 CI 已完成 Compose 容器运行验证，本阶段未增加容器能力。
